# Task: chat lines for a trigger test

A chat program inserts background texts when a chat names their subject. To test it, write lines a person might type. Your bundle holds `SUBJECT NAMES` only: the subjects of an old book, in three groups (core, secondary, other).

Write 40 lines about the subjects, the way someone curious about such a book would write in a chat: questions, remarks, a follow-up. Name the subjects as such a person would, in today's spelling, singular or plural, not always by the listed name; some lines name one subject, some two or three; every core subject at least twice, every secondary one at least once. Then write 10 everyday lines that have nothing to do with the book (weather, food, work, travel).

Each line on its own row: the names of the subjects it is about, exactly as listed and separated by `; `, then ` | `, then the chat line. For an everyday line write `- | ` and the line. Nothing else in the file.

Write the file your task names. Reply with one line: the file written and the number of lines.
